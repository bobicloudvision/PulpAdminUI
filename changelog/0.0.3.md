# 0.0.3

**Released:** 2026-04-15

### Added

- **File repositories:** full support in repository list/create/edit/publish/delete flows
- **File repository API proxies:** `/api/pulp/repositories/file`, `/api/pulp/repositories/file/create`, `/api/pulp/repositories/file/publish`
- **Repository detail mapping:** file repository hrefs are now resolved in `/api/pulp/repositories/detail`
- **Dashboard summary:** file repository counts included alongside RPM and Debian

### Changed

- **Repository UI:** kind toggles now support `RPM`, `DEB`, and `FILE`
- **Create/Edit forms:** file-specific fields (`autopublish`, `manifest`) are available
- **Navigation copy:** repository labels updated to mention file repositories
- **Project branding:** sidebar title now uses `PULP_PROJECT_NAME` via `NEXT_PUBLIC_PULP_PROJECT_NAME`
- **Environment config:** `.env.example` and setup docs include `PULP_PROJECT_NAME`
