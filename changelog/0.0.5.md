# 0.0.5

**Released:** 2026-05-27

### Added

- **Change user password:** new `Change password` action on the users list with dedicated modal and confirmation field
- **Password API proxy:** `PATCH /api/pulp/users/[id]/password` route that forwards a password-only update to Pulp
- **Users service:** `pulpUserService.changePassword` and `usePulpUsers().changeUserPassword` helpers
