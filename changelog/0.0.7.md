# 0.0.7

**Released:** 2026-11-17

### Added

- **Workers overview:** status cards for online workers, running/waiting tasks, database, Redis and storage usage, with a warning when tasks wait but no workers are online
- **Worker details:** `Online` / `All` / `Missing` scope, Busy/Idle/Offline status from heartbeat age, live "last heartbeat" time, current task with elapsed time and a `Tasks` link per worker
- **Services & versions:** content (and, on newer Pulp, API) apps with heartbeats, plus core and plugin versions
- **Task filters:** state chips with counts, task name search and worker filter, all kept in the URL
- **Task table:** live duration and progress columns, newest tasks first
- **Task details:** dialog with timings, queue wait, worker, logging CID, parent/child navigation, progress reports, error traceback and created/reserved resources; live updates while the task runs
- **Cancel tasks:** cancel a single task from the list or the details dialog
- **Bulk cancel:** select tasks and `Cancel selected`, or `Cancel all` waiting/running tasks matching the current filters (up to 1000 per run)
- **Purge old tasks:** delete finished task records older than a chosen age by state, via Pulp's purge task
- **Auto-refresh:** 10s auto-refresh with manual refresh on the workers and tasks pages
- **API proxies:** `/api/pulp/status`, `/api/pulp/tasks/counts`, `/api/pulp/tasks/[id]`, `/api/pulp/tasks/bulk-cancel`, `/api/pulp/tasks/purge`

### Fixed

- **Workers page on older Pulp:** no longer crashes when `/status/` doesn't report `online_api_apps` (pulpcore 3.22)
