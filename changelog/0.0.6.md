# 0.0.6

**Released:** 2026-11-12

### Added

- **User groups & roles:** new `Groups & roles` action on the users list to add/remove group membership and assign/remove user roles
- **Bulk role assignment:** searchable, plugin-grouped role checklist with `Select all` / per-plugin selection, progress and per-role error report; `Remove all` to revoke every assignment
- **Role scope picker:** assign roles globally, to a specific object picked from a dropdown (repository, distribution, remote, …, derived from the role's permissions), or to a custom href
- **Groups column:** users list shows each user's groups
- **Content search:** debounced RPM package search on `/content/list` by name or SHA256, kept in the URL (`?q=`), with spinner, skeleton rows and dimmed results while loading
- **Orphan cleanup page:** trigger Pulp's orphan content/artifact cleanup with an optional protection-time override
- **Package size stats:** RPM repository content shows per-package and total size
- **Retention tooltips:** inline help for `retain_repo_versions`, `retain_package_versions` and publish-after-save on the RPM edit form
- **API proxies:** `/api/pulp/users/[id]/groups`, `/api/pulp/users/[id]/roles`, `/api/pulp/role-objects` and `GET /api/pulp/content/rpm/packages`
- **Content search on older Pulp:** when pulp_rpm doesn't support `name__contains` (e.g. 3.19), search falls back to a short-lived per-user package index and matches name or version case-insensitively
